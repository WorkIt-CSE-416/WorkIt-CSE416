# A built resume is a live view of the experience bank, and what was sent is kept apart

A built resume stores only a choice of entries, bullets and bullet variants, their order and a template; it shows the experience bank's current text, so fixing a typo in the bank fixes it in every built resume. What the student actually downloaded or applied with is stored separately as a sent resume and never changes. Tailoring adds bullet variants to the entry rather than overwriting bullets or copying the resume.

## Considered Options

- **Frozen copy per resume** (the KAN-176 prototype): each resume kept its own copy of the content. Rejected because a fix in the bank never reached existing resumes, tailoring every job multiplied copies, and the recommender could not treat the bank as the one truth about a student.
